# GMQD

购物记录管理单页应用。

当前版本是一个纯静态 HTML 应用，所有记录保存在浏览器 `localStorage` 中，不依赖后端服务。

## 功能

- 商品记录新增、编辑、删除
- 商品图片上传、压缩保存和首页卡片预览
- 新增和编辑时可直接输入品牌，也可从常用品牌候选中选择
- 按状态筛选：待付款、已购买、已发货、已收货、已取消
- 自动统计记录数量和总金额
- 商品详情弹窗
- 深色模式切换，并记住上次主题
- 移动端优先的网格布局

## 本地运行

直接用浏览器打开 `index.html` 即可。

也可以用 Python 启动一个本地静态服务：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080/
```

## 数据说明

记录和图片保存在当前浏览器的 `localStorage.purchase_records` 中。图片会在浏览器内压缩后以 Data URL 保存。

这意味着：

- 换浏览器或换设备不会同步数据
- 清理浏览器缓存可能导致数据丢失
- 图片会自动压缩；如果仍触发浏览器本地存储容量限制，保存时会提示
- 当前版本没有云端备份和多人共享能力

如果要长期使用，建议后续增加导入/导出 JSON，或接入 SQLite/FastAPI 等后端存储。
